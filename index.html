Line Follower Robot

Personal Project May'26-September'26

This project involves the design and development of an autonomous line-following robot using an Arduino, a QTR-8RC eight-channel infrared reflectance sensor array, and two DC geared motors. The robot detects and follows black-tape paths using a multi-zone bang-bang control algorithm that adjusts motor speeds according to the line's position, enabling it to navigate straight sections, curves, and 90-degree turns. The project focuses on improving steering accuracy, sensor calibration, motor-speed control, and line-loss recovery through iterative testing on circular and square tracks, with the goal of achieving reliable navigation across different path shapes.
